# Screenshots

Esta pasta será usada para capturas da versão de demonstração do Diretoria Gestão.

Antes de publicar uma imagem, confirme que ela não contém:

- nomes ou telefones reais de clientes;
- informações de fornecedores;
- valores reais da operação;
- tokens, endereços internos ou credenciais;
- qualquer outro dado comercial ou pessoal.

Capturas recomendadas para o showcase:

1. Dashboard Desktop.
2. Tela de vendas / PDV Desktop.
3. Cadastro de produtos.
4. Caixa e detalhes de movimentação.
5. Tela de conexão/pareamento.
6. Dashboard ou PDV no Android.
7. Leitura de código de barras no Android.

Use dados fictícios nas demonstrações.
